## Privacy Policy

### 1. Who operates AT89LP IDE
- Philip Gricius
- Last updated: 2026/08/24
- Effective date will be updated when this policy changes.

### 2. Data usage
- The extension sends the following data to Lemon Squeezy
  - License key: A key given to the user at purchase used for activation, deactivation and validation.
  - Instance ID: An ID supplied by Lemon Squeezy for validation and deactivation.
  - Instance Name (`VS Code`): Used for activation to identify the instance.
- The extension does not intentionally send source code, firmware, serial data, or project files to the developer or anyone else.
- The license key is stored in VS Code extension storage so the user doesn't have to enter it manually each time.
- The instance ID is stored in VS Code extension storage to verify the correct instance of the license.

#### Third Party
##### Lemon Squeezy
[Privacy Policy](https://www.lemonsqueezy.com/privacy)
- Lemon Squeezy processes payment and transaction data during checkout.
- AT89LP IDE does not receive or store payment card information.

#### The following stays local
- Source code
- Serial communication
- Programming
- Building

#### Retention and deletion
- Lemon Squeezy manages licenses based on their privacy policy.
- The instance ID and license key are not deleted when uninstalling the extension.
- The instance ID and license key are only removed on license deactivation via Visual Studio Code.
